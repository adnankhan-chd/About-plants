
# 🌿 Plant Identification AI

An AI-powered plant identification application
built using Python, Streamlit, and Google Gemini AI.

## Features

- Upload plant images
- Identify plant names
- Display scientific names
- Show botanical classification
- Identify plant groups
- Display plant descriptions
- Show natural habitat and distribution
- Provide plant care information
- Explain plant uses and interesting facts

## Technologies

- Python
- Streamlit
- Google Gemini API
- Google AI Studio
- GitHub

## Installation

### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Open the project directory

cd Plant-Identification-AI

### 3. Install dependencies

pip install -r requirements.txt

### 4. Configure Gemini API Key

Create a local file:

.streamlit/secrets.toml

Add:

GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"

Never upload your API key to GitHub.

### 5. Run the application

streamlit run app.py
